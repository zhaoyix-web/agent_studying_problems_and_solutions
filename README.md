# agent_studying_problems_and_solutions
个人Agent开发学习踩坑知识库，记录Agent开发过程中遇到的全部报错、难题与完整复盘方案。

## 📦 仓库定位
日常学习、搭建Agent项目、调试大模型接口时遇到的Bug、环境配置、调用异常问题统一标准化归档；
不只是粘贴报错堆栈，会完整梳理复现场景、问题根因、多套解决方案、长期避坑总结，避免重复踩同类问题。

## 📂 目录规划（后续逐步创建）
- Python&大模型API：Python脚本、OpenAI兼容调用、阿里云百炼通义千问、httpx网络超时、API Key鉴权类报错
- Agent工程开发：智能体流程调试、工具调用、提示词工程、流式输出异常
- 云服务配置：阿里云百炼平台开通、密钥管理、接口访问、代理冲突问题
- 运行环境：PyCharm依赖、系统代理、库版本兼容、SSL握手连接异常
- 实训项目错题：Agent课程实训、代码笔试易错点、逻辑漏洞复盘

## 📝 统一笔记模板
每一篇踩坑记录固定包含6部分：
1. 问题场景：复现操作、运行环境
2. 完整报错信息/错误代码
3. 根因分析：底层为什么会出现这个问题
4. 多种可行修复方案（临时解决 + 永久规避）
5. 优化总结：后续Agent开发避坑准则
6. 分类标签，方便检索

## 🎯 建设目的
1. 沉淀Agent开发专属知识库，复习时快速回看，避免重复踩同类Bug
2. 锻炼问题拆解、故障排查、技术文字梳理能力
3. 开源分享，供同专业做Agent开发的同学参考，面试可作为持续学习、问题复盘能力证明

## 更新记录
持续更新，每一次Agent开发踩坑都会新建文档提交，记录完整思考与排错过程。
